The docs scripts accept a lone `--` before their options. On a branch other than the default branch, a stale next-version gallery (DS4) is information only. `design_system.py relink vN` accepts a link-only edit of an approved version and records the new digest; the freeze guard template allows it too. A new draft's `CHANGES.md` ends with an example entry in a comment, and the version README template has the section "What the apps do not follow yet".
