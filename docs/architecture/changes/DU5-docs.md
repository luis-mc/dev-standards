The design-system enforcement kit has two new guard templates for TypeScript and Vitest. The raw-controls guard fails a raw button, input, select or textarea in app code. The contrast guard checks every text-on-fill token pair against WCAG 2.2 AA in every theme. Each has a known list that only shrinks.
