# DV503 join guard hook

Owner decision (26 Oct): a release join is light (DL-11), yet join agents were briefed to run the full branch gate (`check:branch --keep-going --time-limit 75`) on the release branch (hours each). The luismc-delivery PreToolUse hook now refuses it.

## Files changed
- `claude/plugins/delivery/scripts/hook_pre_tool.py`: DL-11 checks for Bash/PowerShell commands and for Agent/RemoteTrigger briefs.
- `claude/plugins/delivery/scripts/hooklib.py`: shared `is_release_branch(cfg, branch)` (config `train_branch_re`, default `^release/\d+[a-z]?$`, config `release_branches` globs, `*-integration`).
- `claude/plugins/delivery/tests/test_pre_tool.py`: new, 16 cases.
- `docs/specs/delivery/DELIVERYSPEC.md`: DL-11 enforcement column.
- `docs/specs/changes/DV503-join-guard-hook.md`: change note (delivery plugin minor, DELIVERYSPEC minor); the release fold bumps versions.

## Behaviour
- Command: gate = `pnpm|npm|yarn|bun|npx ... check:branch`, `branch_gate.py`, or `run_suite.py --full`. Denied when the branch in force is a release/integration branch: `--head <ref>`, else a `git checkout|switch <ref>` earlier in the command, else `git rev-parse --abbrev-ref HEAD` in the cwd.
- Brief (local and cloud): a join brief is one whose delivery-block `branch` is a release/integration branch, or whose text has `join.py`, a line starting `Join`, or `join RELEASE-`. Denied if it names `check:branch`, `branch_gate.py`, `--full`, `--keep-going` or `--time-limit`. The check runs before D4/DL-37/DL-36 so its reason is the one shown.
- On by default; `checks_off: ["DL-11"]` turns both off.
