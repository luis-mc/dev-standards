CI runner costs

Rented GitHub runners from one vendor that covers Linux, Windows and Mac (for a native iOS app built on every change), against buying machines to run at home. Prices were read from each vendor's own pricing page today. Nothing was signed up for or spent.

Our usage

  • Linux: about 7,000–20,600 minutes a month on rented 8-core machines.
  • Windows: about 2,400–4,750 minutes a month on 4-core machines.
  • iOS (assumed): 15 min per build, ~2.5 builds a day, so about 1,125 Mac minutes a month.

The range is wide (about 3×) because the last 100 CI runs cover only 2 busy release days. Rented machines are smaller than this PC's 10-CPU CI box, so the minutes were scaled up 1.3× for Linux and 1.5× for Windows. We'll measure again after a switch.

Recommendation

Rent from Blacksmith, about $190–450 a month, with Namespace or WarpBuild as the fallback. Switching is about one agent-day, mostly Windows setup. Don't buy hardware now: it pays back within a year, but it brings back the dependence on machines at home that you want to remove.

Before spending

  • Your rule is no spending without your approval. Each option above is a monthly bill.
  • Not yet checked: whether each vendor accepts a personal GitHub account (the repo is on yours), and what their Windows machines come with (WiX, signing tools).
  • The monthly range is wide. A spending cap at the vendor keeps a busy month from surprising you.
  • The Claude cloud-session plan costs no money but can't build iOS, and it takes 6–9 days to build.
