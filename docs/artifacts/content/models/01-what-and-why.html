Which model runs which work is a design decision with a cost, so it is specified, versioned and tracked like any other feature.

The owner’s rule (10 October): the definition of which model each agent type uses, and each skill’s profile, is always a feature. The 9–10 October evidence from a real project’s sessions showed why:

  • Merging, conflict resolution, lint fixes and running checks were mechanical. Design contracts, scope and judgment calls were the only work that needed the strongest model.
  • 18 parallel cloud agents used up the 5-hour session limit in about 20 minutes; five at a time finished the same work.
  • Effort was set by hand (effortLevel: high in that repo’s settings on 10 October), not by the setup every project gets.
