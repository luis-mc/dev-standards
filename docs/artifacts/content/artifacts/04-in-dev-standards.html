A new plugin, luismc-artifacts, beside luismc-specs. One script does the work; the skills and hooks call it.

Layout

claude/plugins/artifacts/
  .claude-plugin/plugin.json            name luismc-artifacts, version 1.0.0
  design/default-design.css             the default design tokens (AR14)
  design/DESIGN.md                      how a project's own design is found; the token contract
  references/ARTIFACTSPEC.md            the standard (section 3 here), versioned like STACKSPEC and AUTHSPEC
  scripts/project_artifacts.py          registry, rendering, add-task, set-task-status, stamp, check (stdlib only)
  scripts/hook_after_command.py         queues status changes from git, gh and deploy commands
  scripts/hook_end_of_turn.py           blocks the turn while anything is queued or unpublished
  scripts/hook_session_start.py         queues changes made between sessions
  hooks/hooks.json
  templates/feature-artifact.html
  templates/full-progress-artifact.html
  templates/project-artifact.css        the fixed structure stylesheet
  rules/project-artifacts.md            installed into a project by the first creation skill
  skills/feature-artifact-new/SKILL.md
  skills/full-progress-artifact-new/SKILL.md
  skills/task-add/SKILL.md
  skills/task-status-update/SKILL.md
  skills/project-artifact-check/SKILL.md
.claude-plugin/marketplace.json         add the luismc-artifacts entry
README.md                               a luismc-artifacts section and the install line

.github/workflows/spec-lint.yml         path filters and steps for the above

The five skills

SkillWhat it does
/luismc-artifacts:feature-artifact-newAsks the feature name and the apps it covers, writes a feature artifact with section 0 started and a first History row, registers it in the manifest, and adds its tasks to the registry. Creates the full-progress artifact first if the project has none.
/luismc-artifacts:full-progress-artifact-newWrites the project’s one full-progress artifact with an empty task registry; refuses if one exists. For a project with ongoing work but no feature artifact yet.
/luismc-artifacts:task-addRecords new work as a task, asking which artifact owns it (a feature artifact, or the project), and gives it the next ID.
/luismc-artifacts:task-status-updateReads the artifacts, runs set-task-status, runs the check, and publishes every artifact that changed. Retries after a publish conflict.
/luismc-artifacts:project-artifact-checkChecks a project’s artifacts against ARTIFACTSPEC. Exit 0 clean, 1 findings, 2 unreadable, like spec_check.py.

The default design is in design/default-design.css and templates/project-artifact.css on branch AR14-default-design; these two artifacts use it.
