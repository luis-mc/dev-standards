§ 1What and why

Which model runs which work is a design decision with a cost, so it is specified, versioned and tracked like any other feature.

The owner’s rule (10 October): the definition of which model each agent type uses, and each skill’s profile, is always a feature. The 9–10 October evidence from a real project’s sessions showed why:

  • Merging, conflict resolution, lint fixes and running checks were mechanical. Design contracts, scope and judgment calls were the only work that needed the strongest model.
  • 18 parallel cloud agents used up the 5-hour session limit in about 20 minutes; five at a time finished the same work.
  • Effort was set by hand (effortLevel: high in that repo’s settings on 10 October), not by the setup every project gets.

§ 2Today

Figure 1 corrects the first inventory given in the session: Explore and Plan are not on Sonnet. They run on the main session’s model, so in these projects they run on Opus. Only general-purpose code agents and plugin agents without a model of their own follow CLAUDE_CODE_SUBAGENT_MODEL.

§ 3Where model and effort come from

Two settings carry most of the weight. CLAUDE_CODE_SUBAGENT_MODEL only applies when nothing above it names a model. Per-model effort (modelSettings) is not documented to reach subagents, which is why DS5 also passes the effort on each Agent call.

A skill’s model and effort go in its SKILL.md frontmatter. The model applies for the rest of the turn that runs the skill; the session model resumes on the next prompt. Skills of luismc-artifacts not listed here get their profile when that plugin is built (AR10).

§ 7Decisions

#QuestionDecision (10 Oct)
1Effort for each model of the split?Asked on every setup, high preselected for code agents; top-level effortLevel high for cloud agents.
2Where do the role rules live?In a plugin-owned rule file, .claude/rules/agents-and-integration.md, replaced on every run.
3Override Explore and Plan?No; both stay on the main session’s model (Opus).
4Per-skill profiles?By kind of work: judgment on Opus high, mechanical on Sonnet medium, claude-setup on Sonnet high.
