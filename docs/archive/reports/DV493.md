## New join steps
1. Merge the branches (each agent branch still needs its own trusted gate), resolve lockfile conflicts.
2. Setup (install from the lockfile).
3. typecheck and lint of the packages the merges touched (a step's `"join": true|false` in gate.json overrides).
4. Fast guards (`fast_guards.py`, the pre_push steps); `"join_guards": false` turns them off.
5. Runner health (warn only), push, ready PR. No tests, no branch gate, no re-gate after a join fix.
