# DV438 report: start time and dropped releases

**Cause.** (1) `render_artifacts.py` `_other_row` drew an open no-release task's bar from `task['started']`, else "now", but nothing in `project_artifacts.py` could set `started`, so every waiting or needs-you bar began at "now" and looked like it was running now. (2) No status closed a release truthfully: Live and Failed are false for work folded into another release, and On hold stays in `open_releases` with a bar on the "Next releases" chart.

**Change.**
- `--started "DD Mon ~HH:MM"|HH:MM` on `set-task-status` and `task-add`: same parsing and project zone as `--phase`, stored as ISO with offset, refused unless before Expected (also when a later `--expected` would pass it), `""` clears it, `check` reports a bad one. A task that first moves to Running with none gets now, unless its Expected has already passed. `started` is in the publish fingerprint. ARTIFACTSPEC R5.48; task-status skill.
- New terminal status `Dropped` (R5.49, R6.1): `set-task-status ID Dropped --into ID|RELEASE-n [--reason TEXT]`, or `--reason` alone for a non-release task; a release needs `--into` (another release). Stored as `dropped_into` / `dropped_reason`, removed on reopen. Not in `OPEN_STATUSES`, so it leaves `open_releases` and the timeline; shown in the `Live or built` group with the muted line `dropped: folded into RELEASE-n`, a ninth chip and tile (CSS added); the feature History gets the same line. Record checks: reason or target required, target must be a task (a release for a release), nothing may still ride a dropped release (`--rides` refuses it), the line must match in `check`.
- Why a status and not a flag on On hold: On hold means "will resume", is open and charted by design; a status is what every list, chip, tile and check already switches on, so one new terminal value is consistent everywhere with the least new surface. It reuses `Live or built` rather than adding a group, so no group title changes.
- Version and change log: change note `docs/specs/changes/DV438-start-time-dropped-release.md` (minor), folded by the orchestrator per the notes README.
