# CO669: Full Progress page at narrow widths, collapsible contents

## What changed
- `claude/plugins/artifacts/templates/project-artifact.css`
  - Task tables and the feature list stack into cards with `@container (max-width: 46rem)`. It measures the table box, not the screen, so the 900 px page with the open sidebar stacks too (that was the overlap). Card: status chip + ID + item on top, then labelled lines (Detail, App / service, Expected and its basis, "Rides RELEASE-n"). Text cells use `min-width:0` and `overflow-wrap:anywhere`, and there are no one-letter columns.
  - The feature-artifacts table stacks the same way, including State. The sort buttons stay in a header strip.
  - The contents nav wraps (`@media (max-width: 56rem)`), is no longer a sideways scroller, and keeps the Light / dark button on phones.
  - Release headers wrap. The timeline keeps its own horizontal scroll inside its box.
  - Sidebar toggle: `.layout[data-contents="collapsed"]` is a 2.75 rem rail and the content takes the full width.
- `templates/full-progress-artifact.html` and `feature-artifact.html`: a `Hide contents` / `Show contents` button (`aria-expanded`, `aria-controls`). The choice is kept in `localStorage` (`contents-rail`). Every read and write is in try/catch, so the page renders open when storage fails.
- `scripts/render_artifacts.py`: every cell carries a `data-label`.
- `docs/specs/changes/CO669-full-progress-narrow.md`: change note, `luismc-artifacts` minor. Repo rules forbid editing `"version"` on a branch, so the fold bumps it (1.14.1 to 1.15.0).
- `tools/test_render_artifacts.py`: two new cases. `narrow_width_css_and_labels` covers the media and container queries, the stacked-card labels and the nav wrap. `contents_rail_toggle` covers the toggle markup and the guarded storage script, on both page kinds. Existing fixtures were updated for the `data-label` attributes.

## Widths checked
Headless Chromium on the page rendered from this repo's own `docs/artifacts` record (rendered in a scratch copy, so the committed record is untouched). Screenshots are in `docs/agents/reports/CO669/`: 320 (Full Progress only), 393, 600, 900 and 1300 for both pages, plus `*-1300-collapsed.png`.
At every width there is no page-level horizontal scroll, no `.table-scroll` that scrolls sideways, and no squeezed cell. At 1300 px the toggle shows `aria-expanded=false` and "Show contents", and the choice survives a reload.
