# DS26: CI speed-ups plugin (second run)

Branch `claude/DS26-ci-speedups-plugin`, draft PR #105. The first run added the CI-gate path (`ci_scope.py`,
`agent_ci.py`, `ci_run_times.py`, `join.py --ci-gate`, DL-80..83). This run adds the two parts the owner folded in on 30 Oct.

## What changed
1. **Caps (DL-38)**: `hooklib.py` defaults are now cloud 20, local 3, total 23 (were cloud 8, local 3). A project's
   `.delivery/config.json` `caps` still overrides them. `hook_pre_tool.py` enforces the total as well
   (`total` falls back to cloud + local when a project sets only those two). DELIVERYSPEC DL-38 text updated.
2. **Manual CI merged onto the release code**: `agent_ci.py` (in `tooling/shared/scripts/delivery/`, ported from a
   real project's branch and made generic) now merges each `CODE DONE` branch onto
   `--base` (config `base`, default `origin/master`) with `git merge-tree --write-tree`, pushes a two-parent commit
   (branch head first) to `ci/<task>` (`ci_prefix` configurable), starts the workflow (`workflow`, default `ci.yml`) on it,
   reports conflicts by file and starts nothing, starts one run per head (`started_for_ci`), `--watch N`, `--dry-run`
   (merge check only, pushes nothing). `cleanup.py --pr N` removes the `ci/<task>` refs of the train (the import is
   optional, so a project without `agent_ci.py` is unchanged).
3. Change notes: the existing DS26 notes now cover both parts; one minor bump of each plugin at fold (delivery 0.10.0,
   project-setup 14.7.0). No CHANGELOG file exists here; the notes are the change log, and no version line was edited.
   README (delivery) and DL-81 text updated.
