Read-only review of `main` on 2026-11-27. No repo file was edited or deleted. Only this report and `ds299-structure.md` are written.

## Summary

- Scope: 816 tracked files. Each basename and path was searched across the repo, with extra care for `.github/workflows/`, `tools/`, `plugin.json`, `hooks.json`, `SKILL.md`, `marketplace.json`, `ci-areas.json`, `tools/change-notes.json` and `.claude/suites.json`.
- Not proposed again: what DS293 removed (`docs/archive/`, `cancel_joined_runs.py` and its test, `docs/templates/change-note.md`, two upgrade guides, three retired record features).
- `claude/plugins/artifacts` and `claude/plugins/specs` are **not** plugins. No such folder is tracked, and `marketplace.json` does not list them. DS219 merged both into `luismc-docs`. Only text mentions remain. They are history, plus `.gitleaksignore` entries for old commits, which the full-history secret scan still needs.
- The repo is mostly lean. Almost every file has a caller. Few files are dead. Most of the weight is project-record history (about 2.5 MB in `docs/project/`) and tests that CI never runs.
- **Safe now (3):** U1 an empty stray file `claude/plugins/delivery/tests/C`; U2 two redundant `.gitkeep` files; U3 the vestigial `retired/` comment in `docs/README.md`. (U3 is a text edit, not a deletion.)
- **Delete with edits (9):** U4 the retired no-op `hook_before_command.py`; U5 two tools tests that fail on `main` today and are not in CI; U6 nine more `tools/` tests that only `suites.json` runs; U7 `project-setup/tests/` (never run by CI, two files need pytest); U8 retire the finished feature artifacts through the plugin's own `retire` command; U9 four stale MADRs; U10 the stale CI-runs mockup HTML; U11 the local machine path stored in `docs/project/manifest.json`; U12 empty stub folders `docs/design-system/` and `docs/guides/runbooks/`.
- **Keep (with reasons):** U13 to U22. These cover the record registry, generated docs, `.gitleaksignore`, vendored Mermaid, the lifecycle templates, the orphan guides and others.
- Biggest win with low risk: U5, U6 and U7. They turn about 15 test files that nobody runs into either CI-run tests or deletions. Two of them already fail.
- Biggest size win: U8 (up to about 1.1 MB of feature HTML and content), but only with the owner's confirmation for each feature.
- Two findings are not about unused files, but they matter in a public repo. U11 is a local Windows path committed in the record. `docs/README.md` still describes `archive/` (U3).
- Every delete in a plugin folder needs a change note that names that plugin's `plugin.json`. Tests under `claude/plugins/*/tests/**` are exempt (`tools/change-notes.json`, `plugin_note_exempt`).

## Method

1. A script read every tracked file. It counted the other tracked files that name each file's basename (and, for `.py`, the module name). It skipped the generated `docs/index.html`, `docs/llms.txt` and `docs/docs-map.json`.
2. Every file with 0 or 1 hit was checked by hand for its callers: directory copies (`copytree`, template installers), glob runners (`unittest discover`, `node --test "tests/*.test.ts"`), `${CLAUDE_PLUGIN_ROOT}` hook commands and skill text.
3. Each `tools/test_*.py` was matched against `.github/workflows/*.yml`, `.githooks/*`, `.claude/suites.json` and `tools/ci_areas.py`.
4. Each test file's quoted file paths were checked against tracked files. No test loads a script that is gone. Every miss was a temporary fixture name.
5. The tests that CI does not run were run once on this branch (standard library only, no mutants, no Docker).
6. Copies that might be duplicates were compared byte for byte.
7. `docs_check.py` was run once: 0 errors, 0 warnings. The date check T2 was skipped because the clone is shallow.
