# DL239 report: badge, one page colour, fonts at 90%

**Base check.** Built on `origin/DL234-integration`. `templates/project-artifact.css` and `design/default-design.css` exist.

## What changed (all under `claude/plugins/docs/` unless noted)

1. **Version badge.** New `scripts/gen_badge.py` is the one helper. It reads the plugin's own version from `.claude-plugin/plugin.json`, then the newest version in a local marketplace clone (`~/.claude/plugins/marketplaces/<name>/`, found by plugin name through `marketplace.json`). It never uses the network. States: `latest` (green), `update: X.Y.Z` (amber), `latest: unknown` (neutral). `LUISMC_MARKETPLACES_DIR` points it at another folder (tests use it).
   - Pages with the badge in the header, top right: Full Progress and feature pages (both templates, `{{badge}}`), `docs/index.html` and every `_site` page (`docs_index.py`), the design-system gallery (`design_system.py`).
   - Header line: `features/index.md` and `decisions.md` (second line, HTML comment), `llms.txt` (first line): `Generated by luismc-docs X.Y.Z (state)`.
   - `templates/feature-spec.md` has `generator: luismc-docs <version>`; `artifact_promote.py` writes the real version into a promoted spec; the `feature-spec-new` skill says to set it. Existing specs are not rewritten.
   - **Freshness.** CI has no clone, so its state is `unknown`; a local build may say `latest`. To stop them fighting: `docs_index.py check` (and `docs_check` G1) compare generated text without the badge line (`strip_badge_line`); the record's INV-3 comparisons (`check`, `render`, `refresh_stale`, `mark-published`) compare pages without the flag span (`strip_flag_html`). The name and version stay in the comparison, so a plugin upgrade still re-renders pages.
2. **One page colour.** `render_artifacts.design_css` now returns the default tokens plus the project's `design.css` with these declarations removed: `--paper`, `--surface`, `--surface-2`, `--ink`, `--ink-muted`, `--rule`, `--rule-strong` and any `--font-size*` or `--size*` token. Accents (signal, live, failed, status backgrounds and marks, fonts) still apply, in light and dark. The status `*-bg` tokens count as accents, not page colours. The project's own file is still checked for every token (`own_design_problems`, R5.11). `check` warns which tokens are ignored (`design set` warns too). Docs site and gallery CSS now use the default-design values for background, text, muted, line, accent and code.
3. **Fonts at 90%.** Record CSS: base 16px to 14.4px, `clamp(2rem, 5vw, 3rem)` to `clamp(2rem, 4.5vw, 3rem)`, every px size in the timeline x0.9. Site CSS: 16px to 14.4px, 14px to 12.6px. Gallery CSS: 16px to 14.4px, 12px to 10.8px, and the chart label 10 to 9. rem sizes follow the base. A project's size tokens are ignored (the contract has none). The gallery's drawn samples keep the project's own size tokens.

Docs: `docs/features/docs/spec.md` R5.16 to R5.18, `docs/features/artifacts/spec.md` R5.17, their `changes/DL239.md` notes, and `docs/architecture/changes/DL239-docs-badge-colour-fonts.md` (plugin, minor).
