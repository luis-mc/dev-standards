There are four levels. The first two stop work. The last two only inform.

  • Blocks in session: a Claude hook denies a tool call or blocks the end of a turn. It works only in Claude sessions with the plugin on.
  • Blocks merge: a CI check that is required on the default branch. It works for everyone, people and tools.
  • Warns: a hook prints a message. Nothing stops.
  • None: run on demand.
