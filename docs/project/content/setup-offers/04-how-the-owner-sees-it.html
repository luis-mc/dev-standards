The flow keeps today's rule: ask first, plan everything, confirm once, then apply.

  1. Target question (today): project, user or both, and the effort level.
  2. Status scan, with no writes: each offer is done, missing or broken.
  3. One question page per group, in a single AskUserQuestion call. Each question carries its own context.
    • Enforce: docs, design system, delivery, project record (multi-select; done ones are left out).
    • Delivery mode: warn first, or block now.
    • CI: write the checks workflow, and print the branch-protection command.
    • Other setups: tech-stack-setup audit, auth-setup, one audit run (multi-select, all off by default).
  4. One change plan listing every file and command, confirmed once (step 3 today).
  5. Apply and verify.
  6. Enforcement report: one line per plugin, its level, and the next step when it does not block yet.
