ux-rules.mdRule table UX-1 onward: consistent; reuse components; clear headline and plain words; one primary action labelled by what it does, with its reason; guided flows as a wizard (step bar, one step, Back and the primary); no dead ends; never act on hidden items; only buttons look like buttons; in-page confirmation, never browser dialogs; aligned boxed sections in one grid; one pager for long lists; select all and clear on choice lists; busy buttons; core content first; use the width; phone and desktop for every screen, 44 px targets; accessibility (WCAG 2.2 AA, focus, reduced motion, text for every status); dates, times and numbers one way; status from one source of truth. Each rule names its guard or none yet.
