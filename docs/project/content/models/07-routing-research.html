Study of 27 Nov (MP13 to MP15). Question: can claude-setup say which model and effort each kind of task uses, for the best result at the lowest cost? Start point: a routing policy suggested by another assistant. Each of its claims was checked against Anthropic’s docs and public benchmarks, then the two claims that matter most were tested on this repository’s own work. Nothing in claude-setup has changed yet; the proposals below are open decisions.

4. What it misses

  • Effort defaults. Opus, Sonnet and Haiku 5.5 all default to medium in Claude Code. Anthropic’s advice: raise effort when Claude skips steps; change model when the problem is beyond it.
  • Which setting wins. For a subagent: the Agent call’s model, then the definition’s model, then CLAUDE_CODE_SUBAGENT_MODEL, then the parent’s model. A rule file can route each call without new agent files.
  • Caches belong to one model. Each /model switch, and each opusplan switch out of plan mode, re-reads the whole context once.
  • Tiny tasks stay inline. A subagent’s start (its prompt, tools, hand-back) costs more than a commit message.
  • This repo’s own rule R5 (section 6) says Explore and Plan are not overridden. A Haiku Explore needs R5 changed.

6. Test results

Test 1 (MP14): Haiku Explore against Sonnet Explore

Ten real questions about this repository, each with a known answer checked by hand first: constants, agent definitions, the keybindings asset, the merge-mode default, the U+FFFD refusal, the Full Progress settle time, the CI job of transcript-folds, the CI badge logic, the Stop hook’s two modes, and the ETA check. Questions 7 to 10 need reading logic across files, not one grep. Each ran on the built-in Explore agent with the model set on the call, effort medium, three at a time.

H1 holds for lookups. Haiku took a few more tool calls and wrote longer answers, and once it added a true finding nobody asked for: on question 3 it found that the transcript-folds spec’s R6.3 still says the keybindings asset holds three chords (it holds two since RELEASE-204). Limit: these were questions with one right answer. Research that needs a judgment or a synthesis was not tested and stays on Sonnet.

Test 2 (MP15): Sonnet high against Opus medium on real fixes

Five real fixes from this repository’s history (DS266, DL269, DL272, DL305, DS278). Each agent got a git worktree at the commit before the fix, a bug report written from the fix’s change note, and a rule not to read later history. The fix’s own test, which the agent never saw, decides pass or fail. Each hidden test was checked first: it fails at the parent commit and passes at the fix. Sonnet ran at high effort, Opus at medium, three agents at a time.

What the two failures say.

  • DL272: the hidden test also wants the conflict message to say the branch was cut from an older head. The bug report did not say so. Opus added that hint unasked; Sonnet did the rest right. This is the pattern Anthropic describes: the larger model fills gaps in a loose spec.
  • DS278: both failed, so the brief is at fault, not one model. Three of the eight hidden cases test rendering the brief never mentioned. Both agents also chose the same narrower rule for tasks riding a release that is still To do, because the test harness itself puts riders on such a release.

H2 does not hold as stated. Sonnet high fixed fewer bugs (3 against 4) for less money per pass. Escalation closes the gap: Sonnet first, then Opus on the two failures, costs about $0.94 + $0.68 = $1.62 for the same 4 passes, close to Opus alone ($1.69) but slower. Limits: five fixes is a small sample, and time includes waiting for each agent’s own test runs.

Side finding: the artifact test suite opens a demo Full Progress page in the browser on every local run, because the opener only stays quiet when CI is set (DS283).

7. Routing, decided 27 Nov

The owner chose D6 to D10 on 27 Nov. One change from the proposal: bug fixes stay on Sonnet at medium (D8, the owner’s own answer), and any failure goes to Opus. So the proposal’s two bug-fix rows (Sonnet high for tight specs, Opus medium for loose specs) become one row. Building it into claude-setup is MP17.
