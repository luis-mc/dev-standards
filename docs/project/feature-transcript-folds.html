§ 1What and why

Long diffs from Edit, Write, NotebookEdit and Bash fill the terminal and push the conversation off screen. luismc-transcript-folds is a new plugin in this marketplace that draws each long diff as one line (an icon, the file and line, the lines added and removed) and each finished shell command as one line (the command, cut to fit, then how many lines it printed, its error, or what it changed in files).

  • ctrl+x d shows or hides diffs; ctrl+x f folds or unfolds commands. Two slash commands do the same, so nothing depends on a keyboard shortcut alone.
  • Short diffs (5 changed lines or fewer by default) and any edit Claude asks you to review stay whole.
  • A dim line above the prompt shows both switches and what changed this session: files, lines added and removed.
  • Compact mode (a setting) puts the counts on the edit's own line.
  • Both switches start on; your choice is remembered across sessions.

Why its own plugin. A change to how the transcript is drawn runs inside Claude Code as a mod, and a mod only runs from an enabled plugin. claude-setup copies files, so it enables the plugin and writes the two shortcuts to ~/.claude/keybindings.json as part of the standard setup of every machine.

Written from scratch. The idea is learned from a third-party plugin (hide-diffs); none of its code, names or layout is reused. The logic lives in plain TypeScript files tested with Node's own test runner, so the plugin needs no Claude Code test kit and no npm packages.

D5 Which shortcuts toggle diffs and folded commands?

Chords in Claude Code's own ctrl+x family, both free, on every terminal and OS; slash commands as a fallback. Unlike ctrl+q (flow control) and alt+q (Option on macOS).
