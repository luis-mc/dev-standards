## Changes
1. **`ci_watch.py` post-run hooks** (owner decision 1).
   - Once the verdict is decided (exit 0 or 1), each command in `.delivery/config.json` `ci_watch.post_run` runs for each watched run, in list order, from the repository root, after the ledger record.
   - The command is split with shlex (no shell), then `{run_id}`, `{head}` (full sha), `{conclusion}` and `{workflow}` are replaced word by word. `python`/`python3` fall back to the running interpreter when not on PATH.
   - A non-zero exit, a timeout, a command that cannot start, or an unreadable/malformed config is logged on stderr (`ci_watch: post_run hook failed ...`); the next hook still runs; the exit code is never changed. Hook output is passed through. Nothing runs after exit 2 or 4.
   - New flags: `--no-post-run`, `--config FILE`. Docstring, tooling README and CONTRACT.md updated.
2. **Config schema** (`luismc-delivery` `config-schema.json`) lists `ci_watch.post_run` and `ci_watch.post_run_timeout_seconds` so the keys do not warn.
3. **gitleaks in `agent_setup.sh`** (owner decision 2): no code change needed. The script already installs gitleaks at the version pinned in `tools.json`, SHA-256 checked against the pin (old form: the release checksums file), into `$DELIVERY_BIN` (default `~/.local/bin`), and skips when the pinned version is already on PATH. What was missing was a test of the skip; added.
4. Change notes: `DS30-ci-watch-post-run-hooks.md` (project-setup, minor), `DS30-delivery-config-ci-watch.md` (delivery, patch).
